# 📖 About
**Labirinto** is an interactive web application that allows you to generate, visualize, and solve mazes using various algorithms. Built entirely with HTML, CSS, and Vanilla JavaScript (without any external frameworks), the project showcases the practical mechanics of classic pathfinding algorithms such as A*, Greedy Best-First Search, and BFS (Breadth-First Search). It also features several generation strategies like Kruskal, DFS, and Prim. Users can dynamically configure the map size, draw obstacles, and adjust the search speed in real-time.

# 📋 Reason
The project was originally implemented as an experimental foundation for a much larger idea. The future goal is to evolve this mapping and pathfinding logic to create a complex, interactive university campus map designed to efficiently guide students through the campus grounds.

# 💻 Getting Started

### Requirements
- A modern web browser (e.g., [Google Chrome](https://www.google.com/chrome/), [Mozilla Firefox](https://www.mozilla.org/en-US/firefox/new/)).

### Installation

#### Native / Manual Execution
Since this is a static web project, there is no need for a dedicated server or dependency installation.

1. Clone the project repository:
  ```sh
  git clone https://github.com/bgluis/Labirinto.git
  ```

2. Navigate to the project directory:
  ```sh
  cd Labirinto
  ```

3. Open the `index.html` file in your browser:
  ```sh
  # On Windows
  start index.html
  
  # On Linux
  xdg-open index.html
  
  # On macOS
  open index.html
  ```
